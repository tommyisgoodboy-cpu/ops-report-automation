# VPN troubleshooting

## VPN keeps disconnecting
If the VPN drops every few minutes, first check the Wi-Fi signal and switch to a cable if possible. Then update the VPN client to the latest approved version. If it still drops, collect the client log and escalate to the Network team.

## VPN cannot connect at all
Confirm the user's account is not locked and the password has not expired. Check that the device clock is correct, because a wrong clock breaks certificate checks. Try another network to rule out a blocked port.
