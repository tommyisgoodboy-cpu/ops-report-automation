# Wi-Fi troubleshooting

## Cannot connect to Wi-Fi
Check that Wi-Fi is switched on and airplane mode is off. Forget the network and join it again. Move closer to the access point and make sure the network name is in the list. If other devices connect fine, restart the laptop's network adapter. If many people in the same area cannot connect, report it to the Network team with the location and time.

## Cannot sign in to Wi-Fi
If the Wi-Fi asks for a username and password, use the company account and check that it is not locked and the password has not expired. If the login page does not appear, open a browser and go to a plain http address to trigger it. A wrong device clock breaks certificate checks, so check the date and time. If the password was changed recently, forget the network and sign in again with the new password.
