# Printer troubleshooting

## Printer shows offline
Check the printer is powered on and connected to the network. Restart the print spooler service on the user's PC, then remove and re-add the printer. If many users are affected, check the print server before touching individual PCs.

## Paper jam or toner problems
For a paper jam, open every access panel and remove all torn paper, not only the visible sheet. For faint prints, replace the toner cartridge and print a test page. Record the printer asset tag in the ticket.
