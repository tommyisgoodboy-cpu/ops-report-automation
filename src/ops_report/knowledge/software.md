# Software troubleshooting

## Excel or Outlook crashes
Start the application in safe mode to check whether an add-in is the cause. Disable add-ins one by one. For Outlook, rebuild the profile if safe mode does not help. Back up local data before rebuilding.

## Application update or installation fails
Check disk space and that the user has permission to install. Use only approved software packages from the software catalogue. Collect the error code and installer log before escalating.
